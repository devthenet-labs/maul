  1. An Integration and a Forge custom resource (render them with the
     `integrations:` / `forges:` values arrays, or apply your own). The
     Integration validates webhooks and projects tracking issues; the Forge
     clones and pushes repositories.

       * the forge/provider credential (keys: appID + privateKey, or token,

         {{ .Release.Namespace }}, named by each CR's spec.secretRef.

         namespace {{ .Release.Namespace }} ({{ .Values.egressBroker.anthropicSecret }}, key api-key, when the

         enabled for findings or for evaluations, each need a Secret in
         namespace {{ .Values.agent.namespace }}
         ({{- range $id, $r := .Values.agent.runners }}{{ if and (include "patchy.harnessEnabled" (dict "root" $ "id" $id)) $r.secret }} {{ $r.secret }} (key {{ $r.secretKey }}, as {{ $r.secretEnv }}){{ end }}{{- end }} — none needed when claude is the only harness enabled).
